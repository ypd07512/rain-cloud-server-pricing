看懂这张表要区分两件事。

**轻量和 CVM/ECS 不是一类产品。** 28 元、38 元那些几乎都是轻量应用服务器，有月流量包上限、共享 CPU、网络隔离。同配置的常规 CVM/ECS 价格通常是轻量的 2–3 倍。轻量适合个人站和测试，轻量不适合高并发。

**带宽写法差别很大。** 阿里云轻量的 200M 是峰值带宽，持续吞吐受流量包和调度策略限制；京东云、芯飞云标的 5M/10M 一般指独享带宽。雨云表里写的是上行/下行两个数，10M 上行配 50M 下行，下行更宽，适合网页对外提供内容这种读多写少的场景。

价格还有一层时效问题。表里的大厂价来自 2026 年 10–11 月的公开活动页，实际下单价受地域、优惠券、账号标签影响，控制台报价才是最终价。

## 谁适合买，谁别买

**可以考虑的情况：**

- 个人博客、内容站、工具站，一个人维护，不需要弹性扩容
- 独立开发者的测试环境和 staging 机器
- 想开 Minecraft、幻兽帕鲁私服的玩家。游戏云支持动态计费，玩家全部下线时不收费，这是它跟普通云服务器最实际的区别
- 需要开技术服务类发票的小团队。雨云是有软件著作权和 ICP 备案的实体企业，能开票
- 不熟悉 Linux 的新手。虚拟主机支持一键预装宝塔或 1Panel，官方口径是三分钟开始建站

**不建议的情况：**

- 日均几万 IP 的商业生产环境，需要明确 SLA 和赔付条款
- 对延迟极敏感的实时应用，节点网络要先自己测
- 本地大模型推理，这类需求该看 GPU 机型，和本文这些套餐没关系

雨云官方口径里提到，目前有超过 30000 个网站跑在它上面，社区用户超过 22000 人。这是品牌公开数据，能说明它没跑路，不能说明它的稳定性达到什么水平。

## 常见问题

**不满意能退吗？**
7 天无理由退订，控制面板里自助点退订，每位用户 3 次机会，款项退回账户余额，需要提现可以提工单。领过消费积分、1 元试用后续费、超过 7 天这三种情况不能退。限流套餐日流量超过 100G 会自动失去无理由资格。

**客服是 7×24 吗？**
不是。公开资料里有 7×22 和 7×16 两种说法，能确认的是深夜只能提工单，白天响应快。买之前把工单通道点开看一眼，比看宣传语有用。

**香港节点和国内节点怎么选？**
香港的优势在带宽和流量，100M–300M 对称带宽、每月 1024GB 流量，20 元起；缺点是国际线路，国内访问延迟要自己测。国内节点带宽小一些但线路在境内，跑面向国内用户的站点更稳。香港节点公开资料里只给了月付价。

**10M 带宽够不够？**
对文字为主的博客、企业展示站、后台接口，够。对图片站、软件下载、视频、大流量 API，不够，直接看香港节点或 35M 上行的高配。

**能开票吗？**
支持开具技术服务类发票，适合需要报销或做成本的小团队。
